# Mod API Demo

This one uses every API call, so if you want to see how something works, look here. It's a content mod, so other players need it too. Use a test save, some of the buttons change it.

Copy the folder into **Mods > Open folder**, press Refresh and enable it.

## Stuff to try

- Press **Run API checks and save counter** in Mods. Restart the game and press it again, the counter should go up.
- Press **Unlock demo cosmetics for this save**, then pick **API Demo Cat** and **API Demo Tux**. Try the blue beanie on them.
- The general store gets a **Mod API Demo** tab with a rod and a perch for $25.
- You can catch **API Demo Perch** in lakes.
- Host **API Demo Island** from the map picker, it's just the main island again.
- Pause > Settings & Mods > Mods has **Show observed gameplay events** and **Toggle gameplay event hooks**.
- Disable it and enable it again from the main menu. The map, shop and loot should come back once, no duplicates.
